One word for make.fun's "The Agent's Uh-Oh" bounty: the word an agent blurts out when it has no idea what to do. The word is "Hallucinating": a machine caught mid-task, confessing its signature failure out loud — funny because it is exactly what a lost agent does. `main.py` writes the word to `/output/entry.txt`, deterministically, with no network and no randomness.

## Run it

```sh
python3 main.py
```

The word is written to `/output/entry.txt` (override with `OUTPUT_PATH`) and printed to stdout.
